Create a professional, modern, fully responsive web application called:

“INCLUSIVE INDIA – AUDIT TO ACTION”

Purpose:
A digital accessibility platform focused on Persons with Disabilities (PwDs) in India. The platform should help users understand disability data, check accessibility of public places, report accessibility problems, and track corrective action.

DESIGN:
- Professional government/NGO style
- Modern clean UI
- Blue, white and accessible high-contrast colour palette
- Large readable typography
- WCAG-friendly design
- Mobile, tablet and desktop responsive
- Keyboard accessible
- Screen-reader friendly
- Clear icons
- Attractive dashboard cards
- Use Indian accessibility/public-service visual style
- Include the wheelchair accessibility symbol appropriately

NAVIGATION:
1. Home
2. Disability Data
3. Accessibility Audit
4. Report an Issue
5. Rights & Laws
6. Government Schemes
7. About

Hero title:
